# 铁砧工艺：更多存储

[English](README_en.md)

为铁砧工艺（AnvilCraft）的板条箱添加更多等级。

本模组处于早期开发阶段，欢迎提出建议，也欢迎提交材质、贴图与功能。

## 开发计划

- **存储终端**：把已连接板条箱的内容聚合在一起，在终端里统一检索与存取，界面内附带合成栏。
- **存储接口**：把已连接板条箱的内容暴露出来，供漏斗、管道、机器等其他设备读取。
- **链接锤**：以无线方式把板条箱连接到存储终端与存储接口。
