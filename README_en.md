# AnvilCraft: More Storage

[简体中文](README.md)

Adds more tiers of AnvilCraft's crates.

This mod is in early development. Suggestions are welcome, and so are contributions of models, textures and features.

## Requirements

| Item | Version |
| --- | --- |
| Minecraft | 1.21.1 |
| NeoForge | 21.1.241 or newer |
| AnvilCraft | 1.6.0+snapshot.2187 or newer |
